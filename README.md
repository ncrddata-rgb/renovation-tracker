# House Renovation Tracker

A simple web app to track the G+2 house renovation (hand-over 25 Dec 2026).
Sign in with Google; only people on the Team list can see the project.

- `index.html` is the app (built from `src/app.html` by `build.sh`).
- `config.js` holds the Firebase settings. With no settings it runs as a demo.
- `seed.js` holds the 85 items from the original Excel plan.
- `firestore.rules` are the access rules to paste into Firebase.

**Developers: start with [HANDOVER.md](HANDOVER.md).**
